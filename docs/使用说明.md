# 双摄相机使用说明

## 运行前准备

1. 使用 Xcode 打开 `DualCamera.xcodeproj`，选中项目导航栏中的 **DualCamera target**。
2. 在 **Signing & Capabilities** 选择自己的 Development Team，并设置唯一 Bundle Identifier。
3. 连接 iPhone 16 Pro，设备上信任开发者证书后点击 Run。
4. 首次运行允许相机权限。首次录制、保存时再按需允许麦克风、“添加照片”权限。

模拟器没有真实前后摄硬件。需要检查界面和合成流程时，在 Scheme 的 Run Arguments 加入 `-fakeCamera`；该模式的彩色占位画面不能替代真机验收。

## 拍照与布局

1. 顶部菜单选择可用的后置镜头。只显示系统当前允许与前摄并发的镜头。
2. 选择“画中画”“左右分屏”或“上下分屏”，以及 3:4、1:1、9:16 成片比例。
3. 画中画模式下，拖动前摄窗口可移动；松手会吸附到最近角落。双指在前摄窗口上捏合选择小／中／大尺寸；在后摄区域捏合则缩放后摄。
4. 点击后摄区域进行对焦／测光；前摄区域不接收该手势。网格、倒计时、镜像和保存选项位于设置菜单。
   缩放手势从开始时的倍率计算，录制中也允许对焦和缩放，但不会重建 Session。
5. 点击白色快门。倒计时结束后，应用在同一事务中并发请求两路照片，随后展示合成结果。

“拍照质量”有两档：快速请求 `.speed`；均衡请求 `.balanced`。若某一路 MultiCam 输出只允许更低上限，应用会安全钳制。切换质量会在空闲时受控重建照片 Session，因此录制或拍照期间设置菜单禁用。

预览和成片共用同一布局参数；不过两路照片是近同步而不是严格同一曝光时刻。

## 照片预览、保存与分享

- “分享”打开系统分享面板，分享合成照片，不会自动写入相册。
- “保存并继续拍摄”按设置保存：默认仅保存合成照片；可改为同时保存合成照片、前摄原图和后摄原图。两张单路照片优先直接写入相机 `fileDataRepresentation()`，不是 `UIImage → JPEG` 的二次编码；仅在系统没有返回文件数据时才记录降级并回退 JPEG。
- 保存中按钮禁用。成功后会震动、显示“照片已保存到系统相册”，自动回到实时预览。
- 若“添加照片”权限被拒绝，应用会显示“去设置”入口；在系统设置中允许该权限后重试。

前摄方向规则：实时预览镜像由“前摄预览镜像”控制；合成照片由“前摄成片镜像”控制；单独保存的前摄相机文件保持相机自然方向。

## 视频

右侧红点开始录制，中央按键停止。当前视频为固定画中画、720×1280 H.264 + AAC；停止后可预览、保存或关闭。关闭和保存成功都会删除缓存临时文件。保存失败后文件保留供重试，选择关闭时删除。

麦克风拒绝只会阻止视频并提供“去设置”，照片仍可继续使用。视频两路帧按最近可用前摄帧合成，属于近同步而非严格硬件逐帧同步。本版本没有新增视频布局、比例、滤镜、暂停继续、4K、ProRes 或后台录制。

## 生命周期与异常

- inactive（权限弹窗、控制中心等短暂状态）不会立即销毁 Session；真正进入后台才停止会话、取消尚未完成的照片工作并结束录制。回到 active 且没有媒体预览时恢复。
- 系统中断时会取消当前事务并提示；中断结束后尝试恢复。
- `mediaServicesWereReset` 会清理并重建会话。单次拍照失败、超时或取消不会把应用永久锁在“拍摄中”。
- 设置菜单中的“硬件诊断”会显示所选格式、帧率、`hardwareCost` 与 `systemPressureCost`。配置时会在 30fps／24fps 候选中有限降级，只有两项成本都不超过 1 才接受；运行期 serious 压力会尝试降至 24fps，critical／shutdown 会停止或阻止录制／会话。

## 常见问题

### 白屏、黑屏或不支持

确认使用的是实体 iPhone，且系统相机、视频通话、屏幕录制等没有占用摄像头。完全退出占用应用后重试。若仍不可用，请记录设置中的硬件诊断并按 [真机验收](真机验收.md) 提交结果。

### Xcode 无法安装到手机

确认在 **Signing & Capabilities** 已选择 Team、Bundle Identifier 唯一，并在“设置 → 通用 → VPN 与设备管理”信任开发者证书。

### 命令行提示缺少 iOS 平台组件

在 Xcode 的 **Settings → Components** 安装与当前 Xcode 匹配的 iOS 平台组件后，重新执行：

```sh
xcodebuild -project DualCamera.xcodeproj -scheme DualCamera \
  -sdk iphoneos -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

### 在 Xcode 中找不到 target

左侧项目导航栏点击最上方蓝色 **DualCamera** 项目图标；中间编辑区左栏会分成 **PROJECT** 和 **TARGETS**。在 **TARGETS** 下点 **DualCamera**（不是顶部 Scheme 设备菜单），右侧选择 **Signing & Capabilities**。
