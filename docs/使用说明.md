# 双摄相机使用说明

## 1. 运行前准备

1. 使用 Xcode 15 或更高版本打开 `DualCamera.xcodeproj`。
2. 在工程的 `DualCamera` target 中选择自己的签名团队。
3. 将 Bundle Identifier 改为自己账户下未被占用的值，例如 `com.your-company.dualcamera`。
4. 用数据线或无线调试连接 iPhone 16 Pro，并在设备上信任开发者证书。

本项目最低部署版本为 iOS 17。模拟器没有可供验证的前后摄硬件，因此只能检查界面编译，不可作为功能验收设备。

## 2. 首次启动

应用首次运行会请求相机权限。请选择“允许”。首次点击录制按钮时会请求麦克风权限；首次点击“保存照片”或“保存视频”时会请求“添加照片”权限。三个权限只用于对应的本地功能。

如果之前选择了“不允许”，请进入：

```text
设置 → 隐私与安全性 → 相机 → 双摄相机
```

重新开启权限后重启应用。麦克风与“添加照片”权限也可在同一应用设置页中重新开启。

## 3. 成功状态

成功启动后应同时看到：

- 后置画面占满主画面；顶部菜单会显示系统允许与前摄并发的超广角、广角或长焦镜头。
- 前置画面固定在右下角，且为镜像效果。
- 点击白色快门后，短暂显示拍摄状态；完成后进入一张合成照片预览。点击“保存并继续拍摄”才会写入系统相册；写入期间按钮禁用，成功后自动返回双摄实时预览并显示短暂成功提示。
- 合成照片以后置画面为背景，前置画面叠加在右下角。
- 点击右侧红点可开始录制；中央快门会变为停止按钮。停止后进入画中画视频预览，点击“保存视频”才会写入系统相册。

关闭照片或视频预览后可继续拍摄。保存成功也会自动返回实时预览；媒体预览显示期间会暂停双摄会话，降低功耗与热负载。应用不会自动保存媒体到“照片”App。

## 4. iPhone 16 Pro 兼容策略

应用并不依赖机型名称，而是在启动时按以下顺序确认：

1. `AVCaptureMultiCamSession.isMultiCamSupported` 为真。
2. 系统公开的 `supportedMultiCamDeviceSets` 包含前置 TrueDepth 与后置广角的组合。
3. 两个摄像头各自存在支持 MultiCam 的 30fps 格式。
4. 为每个摄像头选择 720p 及以上的最低可用格式，以降低硬件带宽和热负载。
5. 录制期间切换为视频／音频数据输出；停止后恢复照片输出，避免长时间叠加高带宽输出。

因此 iPhone 16 Pro 可在系统支持该组合时开启真实的并发双摄；若系统在电话、屏幕录制、相机被占用或热负载过高时拒绝会话，应用会显示原因，不会用单摄冒充双摄。

| 拒绝相机权限 | 显示到“设置”开启权限的说明 |
| 拒绝麦克风或相册权限 | 仅录制或保存功能显示可操作的权限说明，预览与拍照不受影响 |
| 长时间运行/高温 | 系统中断时显示提示，不崩溃 |

## 6. 常见问题

### 只显示黑屏或提示不支持

确认在实体 iPhone 上运行，且没有其他 App（含系统相机、视频通话、屏幕录制）独占摄像头。完全退出占用应用后重新打开本应用。

### Xcode 无法安装到手机

检查 Signing & Capabilities 中已选择开发团队，Bundle Identifier 唯一，并在设备的“VPN 与设备管理”中信任对应开发者。

### 命令行构建提示 iOS 平台未安装

在 Xcode 中打开 **Settings → Components**，安装与 Xcode 匹配的 iOS 平台组件，然后重试：

```sh
xcodebuild -project DualCamera.xcodeproj -scheme DualCamera \
  -sdk iphoneos -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

### 为什么不支持任意后摄镜头组合

并发摄像头由设备的硬件带宽、传感器和系统热策略共同限制。应用会动态检测超广角、广角和长焦与前置 TrueDepth 的组合，只将当前系统明确允许的镜头显示在菜单中。切换镜头时会重建双摄会话；录制和拍照过程中会暂时禁用切换，以确保媒体文件完整。

### 视频按钮无法开始录制

请确认已允许麦克风权限，并保持手机解锁、连接稳定。录制会从照片输出切换到视频输出，首次切换可能有短暂准备时间；若系统因温度、通话、屏幕录制或其他相机 App 占用而拒绝会话，应用会显示原因。
