# iPhone 16 Pro 真机验收

状态说明：自动测试与真机测试分开记录。以下项目尚未在本轮改动后由真人在 iPhone 16 Pro 上逐项完成，均保持未勾选；模拟器或无签名构建成功不能替代这些结论。请使用 Debug 真机包、开启控制台日志，并记录设备、iOS、Xcode、格式候选与异常截图。

## 基础与权限

- [ ] 冷启动，首次允许相机权限，前后预览同时出现。
- [ ] 拒绝相机权限后，状态正确提示并可从系统设置恢复。
- [ ] 首次录制时允许／拒绝麦克风，拍照不受拒绝麦克风影响。
- [ ] 首次保存时允许“添加照片”，相册中可找到照片。
- [ ] 拒绝“添加照片”后，保存失败不退出，点击“去设置”能打开本 App 设置页。
- [ ] 重新授权相册后，不重装 App 也可再次保存。
- [ ] 请求相机或麦克风权限期间切到后台；授权回调返回时不会在后台错误启动 Session，返回前台后可恢复。

## 双摄与镜头

- [ ] iPhone 16 Pro 上同时显示真实前后摄预览，无单摄伪降级。
- [ ] 后置菜单只显示系统允许的镜头组合。
- [ ] 分别切换超广角、广角、长焦（若系统可用），预览恢复且没有崩溃。
- [ ] 拍照或录制中切镜头被安全阻止并给出提示。
- [ ] 设置中格式、帧率、`hardwareCost`、`systemPressureCost` 可读。
- [ ] 冷机默认优先取得 30fps、接近 720p 的组合；记录实际前后格式与两项成本，确认都 `<= 1`。
- [ ] 制造成本较高的镜头／模式组合时能有限降级；如出现 30fps → 24fps，保存完整候选尝试日志且没有无限重建。
- [ ] 每个系统允许的后置镜头分别完成一次拍照和一次视频录制。

## 布局与成片

- [ ] 画中画默认在右下，拖动后不越界，松手吸附最近角落。
- [ ] 画中画小／中／大三档尺寸正确，重启 App 后位置和尺寸保持。
- [ ] 左右分屏：后摄在左、前摄在右，预览与成片一致。
- [ ] 上下分屏：后摄在上、前摄在下，预览与成片一致。
- [ ] 3:4、1:1、9:16 三种比例均能完成拍照，成片尺寸与选择一致。
- [ ] 切换前摄预览镜像与成片镜像，效果分别生效。
- [ ] 保存的前摄单路相机文件保持自然方向；预览镜像和合成镜像互不串扰。

## 拍照体验与媒体

- [ ] 后摄点击对焦／测光有焦点框且对焦生效；点前摄不改变后摄焦点。
- [ ] 后摄双指缩放可用并保持在安全范围；前摄窗口捏合仅调整画中画尺寸。
- [ ] 网格开关和 3／5／10 秒倒计时生效，快门有触感反馈。
- [ ] 快速模式拍照成功，日志中的前后 output max/request 均为安全值，成片后可继续拍。
- [ ] 均衡模式拍照成功，系统允许时请求 `.balanced`，不因超过任一路 max quality 崩溃。
- [ ] 连续拍照 20 次：每次都能进入预览，没有永久“拍摄中”状态，内存没有持续增长。
- [ ] 人为遮挡／中断一次拍照，超时或失败后可再次拍照。
- [ ] 分享仅打开系统分享面板，不会自动写入相册。
- [ ] 默认“仅保存成片”只写入一张；“成片和前后原图”一次写入三张。
- [ ] 导出两张单路照片的文件信息，确认优先保存相机原始文件 Data；若日志显示 JPEG 回退，记录机型、格式和原因。
- [ ] 保存中重复点击被禁用；保存成功后自动回到实时预览并只出现一次成功提示。

## 生命周期、压力与已有视频

- [ ] 拍照进行中切后台，回前台后无卡死、无永久拍摄状态。
- [ ] 打开控制中心或系统权限面板产生 inactive 时，不错误停止／重建 Session；返回后预览连续。
- [ ] 锁屏后解锁，Session 按状态恢复且旧拍照／录制结果不串入新事务。
- [ ] 会话中断（来电、控制中心或相机占用）后提示正确，恢复后可继续拍照。
- [ ] 系统恢复媒体服务后，会话能重建或给出可操作错误。
- [ ] 连续预览／拍照 10 分钟，观察日志和压力成本；serious 有提示并在支持时降 24fps，critical 停止／禁止录制，shutdown 安全停止。
- [ ] 拒绝麦克风后立即连续拍照 3 次，照片链路保持 Ready。
- [ ] 视频录制中触发来电／相机占用／切后台，录制只结束一次，不崩溃，返回后能处理结果或明确失败。
- [ ] 连续视频录制 5 次，每次预览正常、音画可播放，前后帧近同步限制可接受。
- [ ] 视频保存成功后缓存 `.mov` 被删除；关闭预览、新录制覆盖、无帧失败和保存失败后放弃也无残留。
- [ ] 完成／关闭视频后立即拍照，照片模式、质量和前后输出正确恢复。
- [ ] 视频预览关闭后播放器停止，文件不再被占用。
